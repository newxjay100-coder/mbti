# TYPE OF LOVE - Keyboard Edition

키보드로 MBTI 캐릭터를 선택하고, 프로필을 확인하며, 데이트 미션을 진행하는 인터랙티브 웹 애플리케이션입니다.

## 주요 기능
- **MBTI 키보드 인터페이스**: 각 유형별 캐릭터 및 네비게이션 키 제공
- **캐릭터 프로필**: 성격 유형, 특징, 관심사 등 상세 프로필
- **데이트 시뮬레이션**: 단계별 미션 및 선택지에 따른 호감도 반응
- **의상 커스터마이징 (CLOTHES)**: 캐릭터 상/하의 의상 조합 및 프리뷰

## 실행 방법
Node.js가 설치된 환경에서 아래 명령어를 통해 로컬 서버를 실행할 수 있습니다.

```bash
node server.js
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속합니다.
