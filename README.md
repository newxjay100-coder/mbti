# TYPE OF LOVE - MBTI 데이트 시뮬레이션 게임

키보드와 직관적인 인터페이스로 32명의 MBTI 캐릭터를 선택하고, 실제 인지기능 기반 궁합과 상황별 5지선다 질문을 통해 호감도를 쌓아가는 고품격 연애 시뮬레이션 웹 게임입니다.

---

## ✨ 주요 기능

1. **32명 고해상도 MBTI 캐릭터 라인업**
   - 16개 MBTI 유형별 남/여 총 32명의 고유한 고화질(HD) 포트레이트 및 상세 프로필(직업, 가치관, 성향 키워드).

2. **10개 선명한 데이트 코스 & 리얼리티 5지선다 문항**
   - 북카페, 레스토랑, 감성 골목길, 아트 갤러리, 테마파크, 한강공원, 루프탑 바, 해변가, 디저트 카페, 배웅길 등 10개 고화질 명소 순차 진행.
   - 각 장소와 상황에 맞춘 현실적이고 섬세한 5가지 선택지.

3. **실시간 호감도 & MBTI 궁합 게이지**
   - 선택지에 따른 플러스/마이너스 점수 반영 및 역동적인 게이지 반응.
   - 과학적 인지기능(MBTI 궁합 매트릭스) 기반의 기본 케미스트리 측정.

4. **4슬롯 OOTD 코디 시스템**
   - [아우터] / [상의] / [하의] / [슈즈 & 백] 4개 슬롯 구성.
   - [💖 로맨틱], [✨ 시크 & 모던], [🌿 내추럴 캐주얼] 3가지 원클릭 스타일 프리셋.

5. **자체 내장 잔잔한 Lo-Fi BGM (Web Audio API)**
   - 외부 로딩 지연 없는 브라우저 자체 오디오 신시사이저.
   - 마음이 편안해지는 재즈 코드 진행과 앰비언트 차임, 원클릭 ON/OFF 토글.

6. **7단계 심층 엔딩 평가 리포트 (S+ ~ F)**
   - 최종 점수에 따른 다채로운 결과 (S+, S, A, B+, B, C/D, F 등급).
   - 상대방 MBTI(F 감정형 vs T 사고형)에 따른 속마음 독백.
   - 4대 영역별 성적표(심쿵 호감도, 티키타카, 센스/매너, MBTI 궁합) 및 맞춤형 코칭 피드백.

## 🚀 실행 방법

### 방법 1. 웹 서버 실행 (추천)
Node.js가 설치된 환경에서 아래 명령어를 실행합니다:

```bash
node server.js
```

브라우저에서 아래 주소 중 하나로 접속합니다:
- [http://localhost:3000](http://localhost:3000)
- [http://127.0.0.1:3000](http://127.0.0.1:3000)
- (대체 포트: 8080, 5500 지원)

### 방법 2. 서버 없이 바로 실행
`index.html` 파일을 더블 클릭하여 크롬이나 엣지 등 최신 브라우저에서 바로 실행할 수 있습니다.
