GUIDE

레퍼런스 이미지에 맞춘 첫 화면과 구성 설명

1. MBTI 키캡

상단 16개 MBTI 타입 키를 누르면 현재 성별(GIRL/BOY)에 맞는 캐릭터가 선택되고 PROFILE 화면으로 이동해.

2. ESC / GUIDE / MY TYPE

ESC는 HOME으로, GUIDE는 사용 설명, MY TYPE은 추천 안내 영역으로 연결해.

3. 하단 기능 키

HOME / PROFILE / DATE / CLOTHES / TRAVEL / GIFT / SETTING 구조로 키보드와 화면을 연동해.
